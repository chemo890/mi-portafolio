## Instalación y Uso

- Requisito: Tener instalado Git y un navegador web.

1. Ejecuta el comando `git clone https://github.com/usuario/tienda-tecsup.git` para clonar el repositorio.
2. Abre el archivo `index.html` en tu navegador.
